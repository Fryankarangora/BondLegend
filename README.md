# BondLegend

BondLegend is a geo-distributed, event-driven architecture that leverages machine-learning financial data in real-time via autonomous agents and brokers.

The key benefits of using BondLegend include:

- BondLegend is a geo-distributed, event-driven
- architecture that leverages machine-learning financial
- data in real-time via autonomous

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/BondLegend.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure BondLegend, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
